# chatwithsql

# Chat with MySQL using Python and LangChain

This project is a chatbot application that allows users to interact with a MySQL database using natural language queries. It leverages **LangChain**, **FastAPI**, **Streamlit**, and **Ollama** to generate SQL queries based on user inputs and return structured responses.

---

## Features
- **Database Connectivity:** Connects to MySQL using user-provided credentials.
- **Natural Language Processing:** Converts user questions into SQL queries using **LangChain**.
- **LLM Support:** Uses **Ollama (Llama3.2:1b)** for SQL generation and response formatting.
- **Conversational Context:** Maintains chat history to provide context-aware responses.
- **Streamlit UI:** A simple web interface for user interaction.

---
## Comparison with Different LLMs
- **Groq:** Giving error and when running not following prompt rules.
- **llama3.2:1b:** Not following rules some time, and taking ectra time to execute.
- **SQLcode:7b:** Wrong output not worth to waste time.
- **Mistral:** Only error no output, good for count query.
- **Gemini-1.5-pro:** Giving excellent result, with both short and long queries, with less execution time.

## Installation & Setup

### 1. Clone the Repository
```bash
 git clone [repository_link](https://github.com/Itzkuldeep/chat-SQL.git)
 cd chat-with-mysql
```

### 2. Create a Virtual Environment
```bash
python -m venv venv / uconda environment also
source venv/bin/activate   # On macOS/Linux
venv\Scripts\activate     # On Windows
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Set Up Environment Variables
Create a `.env` file and add the following details:
```ini
GROQ_API_KEY
OPENAI_API_KEY
```

### 5. Run the Application
```bash
streamlit run src/app.py
```

---

## Usage
1. Enter MySQL database credentials in the Streamlit sidebar.
2. Click **Connect** to establish a database connection.
3. Ask questions about the database (e.g., "List the top 5 customers by purchase amount").
4. View the SQL query and response generated by the LLM.
